Electricity Price Forecasting Agent

An AI agent that forecasts the System Marginal Price across Vietnam’s wholesale electricity market, 48 half-hour cycles a day.

  • Python
  • statsmodels
  • PostgreSQL / TimescaleDB
  • FastAPI
  • Gemini API
  • ONNX
6.9%WAPE at the next cycle
95k+half-hourly cycles ingested
0.04son-CPU voice transcription
  • Researched SMP formation (merit-order dispatch, price cap, wet/dry hydro regimes, solar duck curve), evaluated exogenous drivers and prioritized them by modeling value, and built a dual-write ingestion pipeline on PostgreSQL/TimescaleDB holding 95,000+ half-hourly cycles (2021–2026).
  • Designed a zero-robust rolling-origin backtest (WAPE, 120 target days across 2021–2026) comparing SARIMAX harmonic regression, persistence baselines and an LSTM; built a multi-horizon forecast router reaching 6.9% WAPE at the next cycle and ~24% at day-ahead (2026 regime), and showed via error decomposition (81% shape-driven) that level-correction approaches cannot close the day-ahead gap.
  • Engineered a bilingual (Vietnamese/English) LLM orchestration layer with Gemini tool-calling: the model only routes and narrates while deterministic Python computes every number, backed by per-forecast provenance records and an offline fallback.
  • Delivered a FastAPI dashboard and chat console (48-cycle SMP curve with P10–P90 uncertainty band) and a local wake-word Vietnamese voice interface (Silero VAD, sherpa-onnx; ~0.04 s CPU transcription).
